

---

### 1. What is “Limiting Results”?

* It means showing **only a fixed number of rows** from a table.
* Useful when the table has a lot of data.

---

### 2. Why Limit Results?

* To view top records
* To improve performance
* To avoid too much output

---

### 3. Syntax (MySQL / PostgreSQL)

```sql
SELECT column_name
FROM table_name
LIMIT number;
```

---

### 4. Examples

#### Example 1: Show First 5 Records

```sql
SELECT * FROM Students
LIMIT 5;
```

#### Example 2: Show Top 3 Highest Marks

```sql
SELECT * FROM Students
ORDER BY Marks DESC
LIMIT 3;
```

#### Example 3: Skip Rows and Then Show

```sql
SELECT * FROM Students
LIMIT 2 OFFSET 3;
```

(Skips first 3 rows, then shows next 2)

---

### 5. SQL Server Syntax

```sql
SELECT TOP 5 * FROM Students;
```

---

### 6. Real Life Example

School wants to display top 5 students with highest marks.
