
---

### 1. What is NULL?

* **NULL** means **no value** or **missing value**.
* It is not zero (0).
* It is not an empty string ('').

---

### 2. Why NULL Exists?

* Sometimes data is unknown
* Sometimes value is not entered yet
* Used to show absence of data

---

### 3. Example Table

| RollNo | Name | Phone      |
| ------ | ---- | ---------- |
| 1      | Amit | 9876543210 |
| 2      | Neha | NULL       |

Neha’s phone number is not available.

---

### 4. Checking NULL Values

We cannot use = NULL.

```sql
SELECT * FROM Students
WHERE Phone IS NULL;
```

To check NOT NULL:

```sql
SELECT * FROM Students
WHERE Phone IS NOT NULL;
```

---

### 5. Important Points

* NULL ≠ 0
* NULL ≠ ''
* Use **IS NULL** and **IS NOT NULL**

---

### 6. Real Life Example

School form where student has not submitted phone number.
