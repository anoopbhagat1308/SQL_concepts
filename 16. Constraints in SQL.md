
---

### 1. What are Constraints?

* **Constraints** are rules applied to table columns.
* They control what type of data can be stored.

---

### 2. Why Use Constraints?

* To maintain data accuracy
* To prevent wrong data
* To keep database reliable

---

### 3. Types of Constraints

| Constraint  | Meaning                      |
| ----------- | ---------------------------- |
| NOT NULL    | Column cannot be empty       |
| UNIQUE      | All values must be different |
| PRIMARY KEY | Unique + Not Null            |
| FOREIGN KEY | Links tables                 |
| CHECK       | Value must follow condition  |
| DEFAULT     | Sets default value           |

---

### 4. SQL Example

```sql
CREATE TABLE Students (
  StudentID INT PRIMARY KEY,
  Name VARCHAR(50) NOT NULL,
  Age INT CHECK (Age >= 5),
  Class INT DEFAULT 8,
  Email VARCHAR(100) UNIQUE
);
```

---

### 5. Real Life Example

* Roll number cannot be empty → NOT NULL
* Email must be different → UNIQUE
* Age must be above 5 → CHECK

---

### 6. Important Points

* Constraints improve data quality
* Can be added while creating table
* Can also be added later using ALTER
