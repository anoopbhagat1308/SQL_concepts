### 1. What is “Truncate table”?

* Command to delete all rows from a table while keeping the table structure (columns, data types, and constraints) completely intact.
* We use the **TRUNCATE** command.

---

### 2. Why Truncate table?

* To remove wrong or old records
* To clean unnecessary data
* To maintain accurate database

---

### 3. Syntax

```sql
TRUNCATE TABLE table_name;
```

---

### 4. Examples

#### Example 1: Delete complete Student table

```sql
TRUNCATE TABLE Students;
```

Instead of deleting rows one by one, MySQL drops the entire table under the hood and recreates it empty
```
