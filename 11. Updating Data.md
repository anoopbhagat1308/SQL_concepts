

---

### 1. What is “Updating Data”?

* It means **changing existing records** in a table.
* We use the **UPDATE** command.

---

### 2. Why Update Data?

* To correct mistakes
* To change marks, address, or details
* To keep database up to date

---

### 3. Syntax

```sql
UPDATE table_name
SET column1 = value1, column2 = value2
WHERE condition;
```

---

### 4. Examples

#### Example 1: Update Marks

```sql
UPDATE Students
SET Marks = 95
WHERE Name = 'Neha';
```

#### Example 2: Update Class

```sql
UPDATE Students
SET Class = 9
WHERE RollNo = 1;
```

#### Example 3: Update Multiple Columns

```sql
UPDATE Students
SET Marks = 88, Class = 8
WHERE Name = 'Amit';
```

---

### 5. Important Note

If **WHERE** is not used, **all rows will be updated**.
