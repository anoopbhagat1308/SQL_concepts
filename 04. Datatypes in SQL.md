
### 1. What are Data Types?

* **Data types** tell the database **what kind of data** can be stored in a column.
* It helps keep data correct and organized.

---

### 2. Why Data Types Are Important?

* Prevents wrong data entry
* Saves memory
* Improves database performance

---

### 3. Main SQL Data Types

| Type    | Used For             | Example      |
| ------- | -------------------- | ------------ |
| INT     | Whole numbers        | 10, 25       |
| FLOAT   | Decimal numbers      | 85.5         |
| CHAR    | Fixed length text    | 'A'          |
| VARCHAR | Variable length text | 'Ravi'       |
| DATE    | Date values          | '2025-09-10' |
| BOOLEAN | True/False values    | TRUE         |

---

### 4. Example Table with Data Types

| Column Name   | Data Type   |
| ------------- | ----------- |
| RollNo        | INT         |
| Name          | VARCHAR(50) |
| Marks         | FLOAT       |
| AdmissionDate | DATE        |

---

### 5. Simple SQL Example

```sql
CREATE TABLE Students (
  RollNo INT,
  Name VARCHAR(50),
  Marks FLOAT,
  AdmissionDate DATE
);
```

---

### 6. Real Life Examples

1. Age of student → INT
2. Student name → VARCHAR
3. Product price → FLOAT
4. Joining date → DATE
