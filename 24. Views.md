
---

### 1. What is a View?

* A **view** is a **virtual table** created from a query.
* It does not store data itself.
* It shows data from one or more tables.

---

### 2. Why Use Views?

* To simplify complex queries
* To improve security (hide some columns)
* To reuse queries

---

### 3. Syntax

```sql
CREATE VIEW view_name AS
SELECT column_name
FROM table_name
WHERE condition;
```

---

### 4. Example

```sql
CREATE VIEW TopStudents AS
SELECT Name, Marks
FROM Students
WHERE Marks > 80;
```

To see view data:

```sql
SELECT * FROM TopStudents;
```

---

### 5. Real Life Example

School creates a view to show only students who scored above 80.

---

### 6. Important Points

* View stores query, not data
* Data updates automatically when table changes
* Can be used like a table
