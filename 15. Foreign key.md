
---

### 1. What is a Foreign Key?

* A **Foreign Key** is a column that **connects one table to another table**.
* It refers to the **Primary Key** of another table.
* It creates a **relationship** between tables.

---

### 2. Why Foreign Key is Important?

* Links related data
* Maintains data accuracy
* Prevents invalid data entry

---

### 3. Example Tables

**Students Table**

| StudentID (PK) | Name | Class |
| -------------- | ---- | ----- |
| 1              | Amit | 8     |
| 2              | Neha | 9     |

**Marks Table**

| MarkID | StudentID (FK) | Subject | Marks |
| ------ | -------------- | ------- | ----- |
| 101    | 1              | Maths   | 85    |
| 102    | 2              | Science | 90    |

Here **StudentID** in Marks table is a **Foreign Key**.

---

### 4. SQL Syntax

```sql
CREATE TABLE Marks (
  MarkID INT PRIMARY KEY,
  StudentID INT,
  Subject VARCHAR(50),
  Marks INT,
  FOREIGN KEY (StudentID) REFERENCES Students(StudentID)
);
```

---

### 5. Rules of Foreign Key

| Rule                   | Meaning                            |
| ---------------------- | ---------------------------------- |
| Must match primary key | Value should exist in parent table |
| Can have duplicates    | Same student can have many marks   |
| Can be NULL            | If relationship is optional        |

---

### 6. Real Life Examples

* StudentID linking students and marks
* CustomerID linking customers and orders
* EmployeeID linking employees and salaries
