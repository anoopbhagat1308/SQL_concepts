
---

### 1. What is an Index?

* An **index** is used to **speed up searching** in a database table.
* It works like an **index page in a book**.

---

### 2. Why Use Index?

* To find data faster
* To improve query performance
* Useful for large tables

---

### 3. How Index Works

* Without index → Database checks every row
* With index → Database jumps directly to required data

---

### 4. Syntax

```sql
CREATE INDEX index_name
ON table_name (column_name);
```

---

### 5. Example

```sql
CREATE INDEX idx_name
ON Students (Name);
```

Now searching by **Name** will be faster.

---

### 6. Types of Index

| Type                | Meaning                     |
| ------------------- | --------------------------- |
| Single Column Index | Index on one column         |
| Composite Index     | Index on multiple columns   |
| Unique Index        | No duplicate values allowed |

---

### 7. Real Life Example

School database with 10,000 students — searching by roll number becomes fast using index.

---

### 8. Important Points

* Improves SELECT speed
* Slows down INSERT and UPDATE slightly
* Should be used on frequently searched columns
