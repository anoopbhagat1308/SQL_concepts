
---

### 1. What is ORDER BY?

* **ORDER BY** is used to **sort the result** of a query.
* It arranges data in **ascending** or **descending** order.

---

### 2. Why Use ORDER BY?

* To see highest or lowest values
* To arrange names alphabetically
* To analyze data easily

---

### 3. Syntax

```sql
SELECT column_name
FROM table_name
ORDER BY column_name ASC/DESC;
```

* **ASC** → Ascending (small to big, A to Z)
* **DESC** → Descending (big to small, Z to A)

---

### 4. Examples

#### Example 1: Sort Marks in Ascending Order

```sql
SELECT * FROM Students
ORDER BY Marks ASC;
```

#### Example 2: Sort Marks in Descending Order

```sql
SELECT * FROM Students
ORDER BY Marks DESC;
```

#### Example 3: Sort Names Alphabetically

```sql
SELECT * FROM Students
ORDER BY Name ASC;
```

#### Example 4: Sort by Class then Marks

```sql
SELECT * FROM Students
ORDER BY Class ASC, Marks DESC;
```

---

### 5. Real Life Example

School wants to see students from highest marks to lowest.

---

### 6. Important Points

* Default sorting is **ascending**
* Can sort by multiple columns
* Works with numbers and text
