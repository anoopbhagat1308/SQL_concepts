
### 1. What is “Inserting Data”?

* It means **adding new records** into a table.
* We use the **INSERT** command.

---

### 2. Why Insert Data?

* To store new student, customer, or product information
* To update database with fresh records

---

### 3. Syntax

```sql
INSERT INTO table_name (column1, column2, column3)
VALUES (value1, value2, value3);
```

---

### 4. Insert Single Row Example

```sql
INSERT INTO Students (RollNo, Name, Class, Marks)
VALUES (1, 'Amit', 8, 85);
```

---

### 5. Insert Multiple Rows Example

```sql
INSERT INTO Students (RollNo, Name, Class, Marks)
VALUES
(2, 'Neha', 9, 90),
(3, 'Ravi', 8, 70),
(4, 'Anita', 7, 88),
(5, 'Karan', 9, 76);
```

---

### 6. Insert Without Column Names

```sql
INSERT INTO Students
VALUES (6, 'Riya', 7, 92);
```

Column order must match table structure.

---

### 7. Real Life Example

School adds new student details into database when admission happens.

---

### 8. Important Points

* Column order must match values
* Data type must be correct
* Primary key value must be unique
