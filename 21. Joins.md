
---

### 1. What are Joins?

* **Joins** are used to **combine data from two or more tables**.
* Tables are connected using **common columns** (usually keys).

---

### 2. Why Use Joins?

* To get related data stored in different tables
* To avoid duplicate data
* To build meaningful reports

---

### 3. Types of Joins

| Join Type  | Meaning                                   |
| ---------- | ----------------------------------------- |
| INNER JOIN | Shows matching data from both tables      |
| LEFT JOIN  | Shows all data from left table + matches  |
| RIGHT JOIN | Shows all data from right table + matches |
| FULL JOIN  | Shows all records from both tables        |

---

### 4. Example Tables

**Students**

| StudentID | Name |
| --------- | ---- |
| 1         | Amit |
| 2         | Neha |

**Marks**

| StudentID | Marks |
| --------- | ----- |
| 1         | 85    |
| 2         | 90    |

---

### 5. Examples

#### Example 1: INNER JOIN

```sql
SELECT Students.Name, Marks.Marks
FROM Students
INNER JOIN Marks
ON Students.StudentID = Marks.StudentID;
```

#### Example 2: LEFT JOIN

```sql
SELECT Students.Name, Marks.Marks
FROM Students
LEFT JOIN Marks
ON Students.StudentID = Marks.StudentID;
```

#### Example 3: RIGHT JOIN

```sql
SELECT Students.Name, Marks.Marks
FROM Students
RIGHT JOIN Marks
ON Students.StudentID = Marks.StudentID;
```
