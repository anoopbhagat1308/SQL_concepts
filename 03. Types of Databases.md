
### 1. What are Types of Databases?

Different databases store data in different ways. These types help us choose the right system based on need.

---

### 2. Main Types of Databases

| Type                        | Meaning                                   | Example Use           |
| --------------------------- | ----------------------------------------- | --------------------- |
| Relational Database (RDBMS) | Data stored in tables (rows & columns)    | School, Bank systems  |
| NoSQL Database              | Data not stored in table form             | Social media apps     |
| Object-Oriented Database    | Data stored as objects (like programming) | Software applications |
| Hierarchical Database       | Data arranged like a tree (parent-child)  | Company structure     |
| Network Database            | Data connected like a web network         | Telecom systems       |

---

### 3. Relational Database

* Most common type
* Uses tables
* Uses SQL language

Example:

| ID | Name | Marks |
| -- | ---- | ----- |
| 1  | Amit | 85    |

---

### 4. NoSQL Database

* Does not use fixed tables
* Can store text, images, JSON data
* Fast for large data

Example: Storing Instagram posts and comments.

---

### 5. Hierarchical Database

* Data stored like a **family tree**
* One parent → many children

Example: School → Class → Students

---

### 6. Network Database

* Similar to hierarchical but more flexible
* One record can have multiple parents

Example: A student can join many courses.

---

### 7. Object-Oriented Database

* Stores data as **objects** (like in Python/Java)
* Used in software projects

Example: Game development systems.

---

### 8. Real Life Examples

1. Bank system uses Relational database.
2. WhatsApp uses NoSQL database.
3. Company employee structure uses Hierarchical database.
4. College course system uses Network database.
