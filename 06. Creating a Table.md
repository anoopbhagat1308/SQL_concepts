
### 1. What is “Creating a Table”?

* It means making a **structure to store data** inside a database.
* A table contains **columns** (fields) and **rows** (records).

---

### 2. Why Do We Create Tables?

* To store related data together
* To organize information properly
* To manage student, employee, or product data

---

### 3. Basic SQL Command

```sql
CREATE TABLE Students (
  RollNo INT,
  Name VARCHAR(50),
  Class INT,
  Marks FLOAT
);
```

This creates a table named **Students** with four columns.

---

### 4. Column Meaning

| Column | Data Stored         |
| ------ | ------------------- |
| RollNo | Student roll number |
| Name   | Student name        |
| Class  | Student class       |
| Marks  | Student marks       |

---

### 5. Real Life Example

A school database has a **Students table** to store student information like roll number, name, class, and marks.

---

### 6. Steps to Create a Table

| Step | Action                            |
| ---- | --------------------------------- |
| 1    | Choose database using USE command |
| 2    | Write CREATE TABLE command        |
| 3    | Define column names               |
| 4    | Set data types                    |
