
---

### 1. What is “Selecting Data”?

* It means **reading or viewing data** from a table.
* We use the **SELECT** command.

---

### 2. Why Select Data?

* To see stored records
* To find specific information
* To analyze data

---

### 3. Basic Syntax

```sql
SELECT column_name FROM table_name;
```

To see all columns:

```sql
SELECT * FROM table_name;
```

---

### 4. Examples

#### Example 1: Show All Data

```sql
SELECT * FROM Students;
```

#### Example 2: Show Specific Columns

```sql
SELECT Name, Marks FROM Students;
```

#### Example 3: Using Condition

```sql
SELECT * FROM Students
WHERE Marks > 80;
```

#### Example 4: Sorting Data

```sql
SELECT * FROM Students
ORDER BY Marks DESC;
```

---

### 5. Real Life Example

School wants to see students who scored more than 80 marks.

---

### 6. Important Keywords

| Keyword  | Work       |
| -------- | ---------- |
| SELECT   | Show data  |
| FROM     | Table name |
| WHERE    | Condition  |
| ORDER BY | Sort data  |
