
---

### 1. What is “Deleting Data”?

* It means **removing records** from a table.
* We use the **DELETE** command.

---

### 2. Why Delete Data?

* To remove wrong or old records
* To clean unnecessary data
* To maintain accurate database

---

### 3. Syntax

```sql
DELETE FROM table_name
WHERE condition;
```

---

### 4. Examples

#### Example 1: Delete One Student

```sql
DELETE FROM Students
WHERE RollNo = 3;
```

#### Example 2: Delete Using Name

```sql
DELETE FROM Students
WHERE Name = 'Ravi';
```

#### Example 3: Delete All Records

```sql
DELETE FROM Students;
```

(This removes all rows but keeps table structure.)

---

### 5. Important Points

* Always use **WHERE** to avoid deleting all data
* DELETE removes rows, not table structure

---
