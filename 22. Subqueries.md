
---

### 1. What is a Subquery?

* A **subquery** is a **query inside another query**.
* It helps to use the result of one query inside another.

---

### 2. Why Use Subqueries?

* To solve complex problems
* To filter data based on another table
* To make queries more powerful

---

### 3. Syntax

```sql
SELECT column_name
FROM table_name
WHERE column_name OPERATOR (
    SELECT column_name FROM table_name
);
```

---

### 4. Example Tables

**Students**

| StudentID | Name | Marks |
| --------- | ---- | ----- |
| 1         | Amit | 80    |
| 2         | Neha | 90    |
| 3         | Ravi | 70    |

---

### 5. Examples

#### Example 1: Students with Marks Above Average

```sql
SELECT Name, Marks
FROM Students
WHERE Marks > (SELECT AVG(Marks) FROM Students);
```

#### Example 2: Student with Highest Marks

```sql
SELECT Name
FROM Students
WHERE Marks = (SELECT MAX(Marks) FROM Students);
```

#### Example 3: Using IN

```sql
SELECT Name
FROM Students
WHERE StudentID IN (SELECT StudentID FROM Marks);
```

---

### 6. Types of Subqueries

| Type            | Meaning                          |
| --------------- | -------------------------------- |
| Single Row      | Returns one value                |
| Multiple Row    | Returns many values              |
| Nested Subquery | Subquery inside another subquery |
