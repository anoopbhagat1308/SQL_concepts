### 1. What is HAVING Clause?

* **HAVING** is used to **filter grouped data**.
* It works with **GROUP BY** and aggregate functions.

---

### 2. Difference Between WHERE and HAVING

| WHERE                         | HAVING                      |
| ----------------------------- | --------------------------- |
| Filters rows                  | Filters groups              |
| Used before grouping          | Used after grouping         |
| Cannot use aggregate directly | Can use aggregate functions |

---

### 3. Syntax

```sql
SELECT column_name, AGG_FUNCTION(column_name)
FROM table_name
GROUP BY column_name
HAVING condition;
```

---

### 4. Example Table

| Class | Marks |
| ----- | ----- |
| 8     | 80    |
| 9     | 90    |
| 8     | 70    |

---

### 5. Examples

#### Example 1: Classes with Total Marks > 150

```sql
SELECT Class, SUM(Marks)
FROM Students
GROUP BY Class
HAVING SUM(Marks) > 150;
```

#### Example 2: Classes with Average Marks > 75

```sql
SELECT Class, AVG(Marks)
FROM Students
GROUP BY Class
HAVING AVG(Marks) > 75;
```

---

### 6. Real Life Example

School wants classes where total marks are above 150.

---

### 7. Important Points

* HAVING is used after GROUP BY
* Works with SUM, COUNT, AVG, etc.
* WHERE filters before grouping
