
---

### 1. What is a Database?

* A **database** is a place where **data is stored in an organized way**.
* It helps us **save, manage, and find information easily**.
* Data is stored in the form of **tables**.

---

### 2. Why Do We Need a Database?

* To store large data safely
* To find data quickly
* To avoid data loss
* To manage data for schools, banks, hospitals, websites

---

### 3. Where Databases Are Used?

* School student records
* Bank customer details
* Hospital patient reports
* Online shopping orders
* Social media accounts

---

### 4. Database Structure

A database contains **tables**.

Example Table: **Students**

| RollNo | Name | Class | Marks |
| ------ | ---- | ----- | ----- |
| 1      | Amit | 8     | 85    |
| 2      | Neha | 9     | 90    |
| 3      | Ravi | 8     | 70    |

* **Row** → One record (one student)
* **Column** → One field (Name, Marks, etc.)

---

### 5. Types of Databases (Basic)

| Type                    | Meaning                                |
| ----------------------- | -------------------------------------- |
| Relational Database     | Data stored in tables (like MySQL)     |
| Non-Relational Database | Data stored in other formats like JSON |

---

### 6. Real Life Examples

1. School app stores student data in database.
2. ATM machine checks account balance from database.
3. Amazon stores product details in database.
4. Hospital system saves patient reports in database.
