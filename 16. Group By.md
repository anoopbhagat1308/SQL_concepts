
---

### 1. What is GROUP BY?

* **GROUP BY** is used to **group rows that have the same values**.
* It is mostly used with **aggregate functions**.

---

### 2. Why Use GROUP BY?

* To summarize data
* To calculate totals for each group
* To analyze data category-wise

---

### 3. Syntax

```sql
SELECT column_name, AGG_FUNCTION(column_name)
FROM table_name
GROUP BY column_name;
```

---

### 4. Example Table

| Class | Marks |
| ----- | ----- |
| 8     | 80    |
| 9     | 90    |
| 8     | 70    |
| 9     | 85    |

---

### 5. Examples

#### Example 1: Total Marks by Class

```sql
SELECT Class, SUM(Marks)
FROM Students
GROUP BY Class;
```

#### Example 2: Average Marks by Class

```sql
SELECT Class, AVG(Marks)
FROM Students
GROUP BY Class;
```

#### Example 3: Count Students per Class

```sql
SELECT Class, COUNT(*)
FROM Students
GROUP BY Class;
```

---

### 6. Real Life Example

School wants total marks for each class.

---

### 7. Important Points

* Every column in SELECT must be in GROUP BY or used with aggregate
* Used with SUM, COUNT, AVG, etc.
