
### 1. What are Aggregate Functions?

* Aggregate functions perform **calculation on multiple rows**.
* They return **one single result**.

---

### 2. Why Use Aggregate Functions?

* To calculate totals
* To count records
* To find average values
  

---

### 3. Main Aggregate Functions

| Function | Work          |
| -------- | ------------- |
| SUM()    | Adds values   |
| COUNT()  | Counts rows   |
| AVG()    | Finds average |

---

### 4. Example Table

| RollNo | Name | Marks |
| ------ | ---- | ----- |
| 1      | Amit | 80    |
| 2      | Neha | 90    |
| 3      | Ravi | 70    |

---

### 5. Examples

#### Example 1: Total Marks

```sql
SELECT SUM(Marks) FROM Students;
```

#### Example 2: Count Students

```sql
SELECT COUNT(*) FROM Students;
```

#### Example 3: Average Marks

```sql
SELECT AVG(Marks) FROM Students;
```

---

### 6. Real Life Example

School calculates total and average marks of students.

---

### 7. Important Points

* Used with SELECT
* Often used with GROUP BY
* Ignore NULL values
