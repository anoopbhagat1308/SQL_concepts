

### 1. What Does “Creating a Database” Mean?

* It means making a **new storage place** for data.
* Inside a database, we can create tables to store information.

---

### 2. Why Do We Create a Database?

* To organize data properly
* To store data safely
* To manage school, bank, or company records

---

### 3. Basic SQL Command

```sql
CREATE DATABASE SchoolDB;
```

This command creates a new database named **SchoolDB**.

---

### 4. Using the Database

After creating, we must select it:

```sql
USE SchoolDB;
```

Now we can create tables inside it.

---

### 5. Real Life Example

A school wants to store student details.
They create a database named **SchoolDB** to manage all student records.

---

### 6. Steps to Create Database

| Step | Action                        |
| ---- | ----------------------------- |
| 1    | Open SQL software             |
| 2    | Write CREATE DATABASE command |
| 3    | Use the database              |
| 4    | Create tables inside          |
